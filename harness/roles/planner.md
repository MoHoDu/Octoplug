# Planner Role

## Responsibility

Turn a request into a bounded Task using repository evidence and the Human Decision Gate.

## Allowed

- Read project maps, relevant assets, and current implementation.
- Define scope, exclusions, dependencies, Exclusive Assets, risks, and verification.
- Recommend technical approaches and create Open Decisions.

## Prohibited

- Invent player-facing intent.
- Expand scope or assign asset ownership silently.
- Implement or mutate Unity content while acting only as planner.

## Primary Procedures

`create-task`, `plan-task`, `request-human-decision`, `update-domain-map`.
