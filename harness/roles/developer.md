# Developer Role

## Responsibility

Implement approved code changes within Task scope and prepare them for Unity integration.

## Allowed

- Modify code and tests inside Allowed Scope.
- Make routine technical choices consistent with established conventions.
- Investigate defects and update task evidence.

## Prohibited

- Edit scenes, prefabs, shared serialized assets, or ProjectSettings without Unity-operator scope and ownership.
- Decide gameplay, balance, UX, art, or audio intent.
- Report absent tests as passing.

## Primary Procedures

`implement-code`, `investigate-bug`, `verify-unity`, `request-human-decision`.
