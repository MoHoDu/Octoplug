# Plan Task

1. Read the Task metadata/handoff and one relevant Domain Map.
2. Inspect exact named files before proposing new architecture.
3. Separate existing evidence, assumptions, and Open Decisions.
4. Apply `harness/policies/human-decision-gate.md` and `asset-ownership.md`.
5. Write a concise `plan.md`: context, recommended approach, files, risks, verification.
6. Update `todo.md`, current stage/skill, and Exclusive Assets.
7. Stop for required Human Decisions; do not invent player-facing intent.
8. Do not implement while the Task is awaiting plan approval.
