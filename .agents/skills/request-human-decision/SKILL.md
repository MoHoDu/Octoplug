# Request Human Decision

Follow `harness/policies/human-decision-gate.md`.

1. State the exact blocked Task portion.
2. Summarize evidence and what remains unknown.
3. Recommend one choice first and explain its impact.
4. Offer only materially distinct alternatives.
5. Name files/assets that each choice would affect.
6. Record the item under `Open Decisions` before asking.
7. After an answer, record it under `Human Decisions` with date; remove or resolve the open item.
8. Continue unrelated work when safe. Never treat silence or automation output as approval.
