# Art Handoff

1. Confirm approved visual direction and Allowed Scope.
2. List source and exported files, dimensions, format, transparency, pivot/slicing, PPU, and naming.
3. State intended scene/prefab/UI placement and variants.
4. Record unresolved import, sorting, animation, or layout questions as Open Decisions.
5. Do not replace existing assets or mutate prefabs/scenes without Exclusive Assets.
6. Verify files open correctly and identify any Git LFS requirement.
7. Hand off Unity import/integration to an authorized Unity operator.
